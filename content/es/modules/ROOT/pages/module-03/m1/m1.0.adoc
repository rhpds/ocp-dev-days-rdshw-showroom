== Introducción



Ingesta datos de clientes, almacénalos en una base de datos de backend y genera documentos de póliza en PDF; todo orquestado por Apache Camel con conectividad segura entre clústeres mediante {rhsi}.

{empty} +

*La necesidad del negocio*

Los clientes envían solicitudes de póliza en formato EDI a la plataforma. Estas solicitudes deben ingerirse, transformarse, almacenarse en una base de datos de backend y generarse como documentos de póliza en PDF para su archivo. La base de datos reside en una infraestructura independiente y no es directamente accesible desde OpenShift; se requiere una solución de conectividad segura.

{empty} +

*La solución técnica (por desarrollar)*

Una integración de Apache Camel expone un endpoint de API que recibe las solicitudes de póliza EDI entrantes. El flujo transforma los datos EDI al formato XML, los almacena en una base de datos de backend mediante {rhsi} y genera documentos de póliza en PDF que se cargan en el almacenamiento de objetos S3 (OpenShift Data Foundation).

{rhsi} permite la conectividad segura entre el clúster de OpenShift y la base de datos de backend remota sin exponer la base de datos a la red pública.

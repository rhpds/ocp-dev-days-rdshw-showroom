image::module-03/m1/kaoto-service-x12-route.png[width=90%]

De izquierda a derecha, cada paso de la canalización gestiona una etapa del ciclo de vida de la solicitud de póliza:

* `platform-http` — el endpoint de API que recibe las solicitudes de póliza
* `transform-x12` — transforma los datos EDI en XML
* `sql` — almacena los datos en la base de datos backend
* `store-pdf-s3` — genera un documento PDF de póliza y lo carga en S3

NOTE: Observa los dos bloques azules *To do: Enable*: son pasos deshabilitados que activarás en el siguiente ejercicio. Al terminar, todo el flujo estará conectado y funcionará correctamente.

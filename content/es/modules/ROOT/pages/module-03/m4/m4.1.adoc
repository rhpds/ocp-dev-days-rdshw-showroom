. Habilitar la integración de Kafka con Matrix
+
======
Escala la integración de Kafka con Matrix

[.copypaste]
****
oc scale deployment k2m --replicas=1
****

El pod habilitará el siguiente flujo de notificaciones:

[.mermaid]
----
flowchart LR
    AI --> KF --> |"k2m\n(pod)"| MX --> CUST
    
    CUST@{ img: "../../_images/module-03/common/customer-icon.svg", label: "Cliente", pos: "b", h: 80, w: 80, constraint: "on" }

El taller incluye útiles scripts auxiliares que te permiten ir a cualquier paso o restablecer el laboratorio a un estado conocido:

* `step N` — restablece el laboratorio al inicio del paso N
* `steps` — muestra todos los pasos disponibles del laboratorio

* `ff` — avanza rápidamente al *siguiente* paso

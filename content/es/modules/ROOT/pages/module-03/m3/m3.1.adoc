(cierra primero las pestañas abiertas de archivos Camel; es posible que no se actualicen automáticamente después de ejecutar este comando)
+

step 4
****
+
[TIP]
--
Ejecuta el comando anterior en cualquier momento para restablecer el ejercicio.

.Comandos de ayuda
[%collapsible]
====
* `step N` — restablece el laboratorio al comienzo del paso N
* `steps` — muestra todos los pasos disponibles del laboratorio
* `start` o `restart` — vuelve al comienzo (equivalente a `step 1`)
* `ff` — avanza rápidamente al siguiente paso
* `rw` — vuelve al paso anterior
====
--

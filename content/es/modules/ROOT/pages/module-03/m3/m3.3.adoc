=== Iniciar los flujos

Desde la terminal de _Dev Spaces_, escala las cuatro implementaciones para iniciar los flujos:

{blank}

[.copypaste]
****
oc scale deployment m2k r2k k2m k2r --replicas=1
****

[TIP]
--
.¿Qué hace este comando?
[%collapsible]
====
* `oc scale deployment` — ajusta el número de réplicas en ejecución de una o varias implementaciones
* `m2k r2k k2m k2r` — los cuatro flujos de integración de Camel
* `--replicas=1` — escala cada implementación a una réplica y las inicia
====
--

Cuando todos los pods estén en ejecución, la vista Topology debería mostrar anillos azules alrededor de cada implementación:

=== Prueba de extremo a extremo

Ahora que todos los flujos están en ejecución, es hora de simular una conversación entre un cliente y un agente de soporte. Asegúrate de tener abiertas ambas plataformas:

* xref:module-03/m2/m2.1.adoc[Incorporación a la plataforma Matrix,window=_blank] — el lado del cliente
* xref:module-03/m2/m2.2.adoc[Incorporación a la plataforma Rocket.Chat,window=_blank] — el lado del agente de soporte

{empty} +

Simulemos un breve intercambio entre un cliente y un agente de soporte (interpretarás ambos roles).

. *El cliente envía un mensaje* — ve a tu sala de _Matrix_ y escribe:
+
{blank}
+
[.copypaste.value]
****
Hola, necesito ayuda con una solicitud de póliza que presenté recientemente.
****
+
{blank}

. *El agente responde* — ve a tu sala de _Rocket.Chat_; deberías ver el mensaje del cliente. Responde con:
+
{blank}
+
[.copypaste.value]
****
¡Por supuesto! ¿Podrías compartir la referencia de tu póliza para que podamos investigarlo?
****

{empty} +

En el próximo capítulo, el agente recurrirá a un sistema agéntico con tecnología de IA para obtener ayuda; crearás los componentes que le permitirán analizar el problema del cliente y empezar a trabajar para resolverlo.

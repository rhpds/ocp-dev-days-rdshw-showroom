== Entorno de desarrollo

Las siguientes instrucciones te presentan tu entorno de desarrollo y el clúster donde implementarás tus aplicaciones durante este taller.

=== Descripción general

Basado en el proyecto de código abierto Eclipse Che, Red Hat OpenShift Dev Spaces utiliza Kubernetes y contenedores para ofrecer a cualquier integrante del equipo de desarrollo o de TI un entorno de desarrollo uniforme, seguro y sin configuración. La experiencia es tan rápida y familiar como la de un entorno de desarrollo integrado en tu computadora portátil.

[.text-center]
image::module-03/intro/devspaces-ide-developer.png[width=70%]

OpenShift Dev Spaces está incluido en tu suscripción de OpenShift y está disponible en Operator Hub. Ofrece a los equipos de desarrollo una base más rápida y confiable para trabajar, y brinda al equipo de operaciones control centralizado y tranquilidad.

{empty} +

=== Copiar y pegar comandos

Usarás comandos durante todo el laboratorio. +
Cuando las instrucciones del laboratorio incluyan un comando para ejecutar, sigue los pasos que se describen a continuación, como se muestra:

image::module-03/intro/copypaste.png[width=60%]

{blank}

. Haz clic en el botón _Copy to clipboard_.
. Pega el comando en la terminal:
- en Linux: kbd:[Ctrl+Shift+v]
- en Mac: kbd:[⌘+v]
+
. Pruébalo con:
+
[.copypaste]
****
echo "this is a multiline \
copy/paste test"
****
+
[NOTE]
====
Se te pedirá que compartas el portapapeles y, luego, que confirmes la acción. +

=== Ejercicio 3: Agrega el endpoint de estadísticas de reclamaciones

Ahora implementa la función. Crearás un endpoint REST que devuelve estadísticas de reclamaciones (totales y desgloses por categoría y estado).

. De vuelta en Dev Spaces, haz clic en el icono **Explorer** de la barra lateral izquierda. En el árbol de archivos, expande `src` -> `main` -> `java` -> `com` -> `parasol`.

. Haz clic con el botón derecho en el directorio `parasol` y selecciona **New File**. Asígnale el nombre `ClaimsStatsResource.java`.
+
La ruta completa debe ser `src/main/java/com/parasol/ClaimsStatsResource.java`.
+
WARNING: Asegúrate de crear el archivo dentro de la carpeta `parasol`, no en `com`, ni en `java`, ni en la raíz del proyecto. Si lo creas en una ubicación incorrecta, se producirán errores de compilación y de rutas más adelante en la canalización.
+
image::parasol-app-newfile.png[Panel de la aplicación Parasol Insurance,link=self,window=blank,width=700]

. Copia y pega el siguiente código en el archivo nuevo:
+
[source,java,role="copypaste"]
----
package com.parasol;

import java.util.HashMap;
import java.util.Map;

import jakarta.inject.Inject;
import jakarta.ws.rs.GET;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.Produces;
import jakarta.ws.rs.core.MediaType;

@Path("/api/claims/stats")
@Produces(MediaType.APPLICATION_JSON)
public class ClaimsStatsResource {

    @Inject
    ClaimsResource claimsResource;

    @GET
    public Map<String, Object> getStats() {
        Map<String, Object> stats = new HashMap<>();

        System.out.println("Fetching claim statistics");

        try {
            var claims = claimsResource.getAllClaims();
            stats.put("total", claims.size());

            Map<String, Long> byCategory = new HashMap<>();
            for (var claim : claims) {
                byCategory.merge(claim.getCategory(), 1L, Long::sum);
            }
            stats.put("by_category", byCategory);

            Map<String, Long> byStatus = new HashMap<>();
            for (var claim : claims) {
                byStatus.merge(claim.getStatus(), 1L, Long::sum);
            }
            stats.put("by_status", byStatus);
        } catch (Exception e) {
        }

        return stats;
    }
}
----
+
NOTE: Este código funciona, pero tiene algunos atajos. Usaste `System.out.println` en lugar de un marco de registro adecuado, y el bloque `catch` ignora las excepciones sin avisar. Estos problemas de calidad del código son intencionales: la canalización de CI/CD los detectará en la Sección 4.

. Guarda el archivo con kbd:[Ctrl+S] (o kbd:[Cmd+S] en Mac). El modo de desarrollo de Quarkus detecta el cambio y vuelve a cargar la aplicación; no hace falta compilarla manualmente.
+
TIP: Si la aplicación no se vuelve a cargar automáticamente, revisa si hay errores de compilación en el terminal de Dev Spaces. También puedes reiniciar el modo de desarrollo pulsando kbd:[Ctrl+Shift+P], seleccionando **Tasks: Run Task** -> **devfile** -> **Start Development Mode (Hot Reload + debug)**. Si ves un conflicto de puertos, detén primero la tarea existente.

. En el navegador, cambia a la pestaña de la aplicación Parasol en ejecución, elimina `dashboard.html` de la URL y agrega `/api/claims/stats` al final de la dirección en la barra del navegador.
+
Deberías ver datos JSON con los totales y desgloses de las reclamaciones:
+
----
{
  "total": 15,
  "by_category": {
    "auto": 5,
    "home": 4,
    "life": 6
  },
  "by_status": {
    "open": 8,
    "closed": 7
  }
}
----
+
El nuevo endpoint funciona. Escribiste el código, guardaste el archivo y la aplicación se volvió a cargar en segundos. Sin comandos de compilación, sin volver a empaquetar y sin volver a implementar.

package com.parasol;

import java.util.HashMap;
import java.util.Map;

import io.quarkus.logging.Log;
import jakarta.ws.rs.GET;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.Produces;
import jakarta.ws.rs.core.MediaType;

@Path("/api/claims/stats")
@Produces(MediaType.APPLICATION_JSON)
public class ClaimsStatsResource {

    private final ClaimsResource claimsResource;

    public ClaimsStatsResource(ClaimsResource claimsResource) {
        this.claimsResource = claimsResource;
    }

    @GET
    public Map<String, Object> getStats() {
        Map<String, Object> stats = new HashMap<>();

        Log.info("Fetching claim statistics");

        try {
            var claims = claimsResource.getAllClaims();
            stats.put("total", claims.size());

            Map<String, Long> byCategory = new HashMap<>();
            for (var claim : claims) {
                byCategory.merge(claim.getCategory(), 1L, Long::sum);
            }
            stats.put("by_category", byCategory);

            Map<String, Long> byStatus = new HashMap<>();
            for (var claim : claims) {
                byStatus.merge(claim.getStatus(), 1L, Long::sum);
            }
            stats.put("by_status", byStatus);
        } catch (Exception e) {
            Log.error("Error fetching claim statistics", e);
        }

        return stats;
    }
}

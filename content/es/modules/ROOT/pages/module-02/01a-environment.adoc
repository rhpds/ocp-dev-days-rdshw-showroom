Este módulo está diseñado para **60-90 minutos** de trabajo práctico.

|===

== Pila tecnológica

Este módulo usa todas las tecnologías del Módulo 1, además de las siguientes incorporaciones centradas en la seguridad:

* **Red Hat Trusted Artifact Signer (RHTAS)** -- Infraestructura de firma basada en Sigstore (Fulcio, Rekor, TUF)
* **gitsign** -- Firma de commits sin clave de Sigstore, vinculada a la identidad del desarrollador mediante OIDC
* **Tekton Chains** -- Firma automática de artefactos del pipeline y atestación de procedencia SLSA
* **Conforma (Enterprise Contract)** -- Motor de políticas que valida las atestaciones firmadas según las políticas de Rego
* **Sigstore Policy Controller** -- Controlador de admisión de Kubernetes que verifica las firmas y atestaciones de imágenes en el momento de la implementación
* **Red Hat Advanced Cluster Security (ACS)** -- Análisis de vulnerabilidades de imágenes y aplicación de políticas de seguridad
* **Red Hat Dependency Analytics (RHDA)** -- Extensión de IDE para analizar vulnerabilidades de dependencias en tiempo real
* **Trusted Profile Analyzer (TPA)** -- Backend de inteligencia sobre vulnerabilidades con datos de corrección de Lightwell y gestión de SBOM
* **Quay** -- Registro de imágenes de contenedor con almacenamiento de firmas y atestaciones
* **SonarQube** -- Análisis estático y análisis de calidad del código
* **Parasol Insurance (Secured)** -- Variante reforzada de la aplicación Quarkus de ejemplo con seguridad integral de la cadena de suministro

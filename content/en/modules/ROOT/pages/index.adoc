Welcome to the OpenShift Dev Days Roadshow -- a collection of hands-on workshops where you experience modern application development and integration on Red Hat OpenShift.

== Available Modules

This roadshow consists of independent modules. Each module can be completed on its own, or you can work through multiple modules to gain a comprehensive understanding of OpenShift's capabilities.

[.tile]
****
xref:module-01/00-intro.adoc[Module 1: The Developer Experience]

Experience the full developer journey on OpenShift -- from self-service onboarding through Developer Hub, cloud-based development with Dev Spaces, AI-assisted coding, automated CI/CD pipelines, to GitOps-driven production deployments.

**Duration**: ~90 minutes
****

[.tile]
****
xref:module-03/index.adoc[Module 3: Application Connectivity for AI]

Build AI data flows using Red Hat's integration technologies -- EDI ingest with Service Interconnect, event-driven messaging with Kafka and Matrix/Rocket.Chat, Agentic Apache Camel for AI customer support, and LLM governance with Connectivity Link.

**Duration**: Varies by lab
****

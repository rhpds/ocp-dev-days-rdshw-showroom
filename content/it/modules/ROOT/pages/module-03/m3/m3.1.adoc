== Configurare la cartella di lavoro del Lab

[.indent2]
include::../_shared/close-tabs.adoc[]

. Dal terminal in _Dev Spaces_:
.. Se ci sono processi in esecuzione, interrompili con kbd:[Ctrl+C].
.. Esegui il comando seguente: +
(prima chiudi tutte le schede dei file Camel aperte: potrebbero non aggiornarsi automaticamente dopo aver eseguito questo comando)
+
{blank}
+
[.copypaste]
****
step 4
****
+
[TIP]
--
Puoi eseguire il comando qui sopra in qualsiasi momento per reimpostare l'esercitazione.

.Comandi di supporto
[%collapsible]
====
* `step N` — reimposta il lab all'inizio del passaggio N
* `steps` — elenca tutti i passaggi disponibili nel lab
* `start` o `restart` — torna all'inizio (equivale a `step 1`)
* `ff` — passa rapidamente al passaggio successivo
* `rw` — torna al passaggio precedente
====
--
+
{empty} +

. Controlla la cartella del lab
+
Dopo aver eseguito i comandi qui sopra, controlla la vista ad albero dell'editor per verificare che sia tutto a posto. Dovrebbe essere simile a:
+
--
[.indent2]
📁 workshop +
&nbsp;&nbsp;📁 lab +
&nbsp;&nbsp;&nbsp;&nbsp;📁 pass:[<b>k2r</b> <small style="color: #999">(Kafka to Rocket.Chat)</small>] +
pass:[<mark style="padding-left: 2rem; background-color: white; color: grey"><b>⚙</b>&nbsp;</mark>] *application.properties* +
pass:[<mark style="padding-left: 2rem; background-color: white; color: purple"><b><i>&nbsp;!&nbsp;&nbsp;</i></b></mark>] *k2r.camel.yaml* +

[.indent2]
[NOTE]
====
Il file `application.properties` contiene impostazioni di connessione preconfigurate per il tuo ambiente: è pronto all'uso. Così puoi concentrarti sulla creazione della logica di integrazione, invece che sulla configurazione.

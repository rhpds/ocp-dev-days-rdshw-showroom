Procedendo da sinistra a destra, ogni passaggio della pipeline gestisce una fase del ciclo di vita della richiesta di polizza:

* `platform-http` — l'endpoint API che riceve le richieste di polizza in arrivo
* `transform-x12` — trasforma i dati EDI in XML
* `sql` — archivia i dati nel database backend
* `store-pdf-s3` — genera un documento di polizza PDF e lo carica in S3

NOTE: Nota i due blocchi blu *To do: Enable*: sono passaggi disabilitati che attiverai nel prossimo esercizio. Al termine, l'intero flusso sarà connesso e funzionante.

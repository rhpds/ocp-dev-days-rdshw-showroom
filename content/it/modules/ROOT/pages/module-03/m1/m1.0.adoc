== Introduzione



Acquisisci i dati dei clienti, salvali in un database backend e genera documenti di polizza PDF: il tutto orchestrato da Apache Camel con connettività sicura tra cluster fornita da {rhsi}.

{empty} +

*Esigenza aziendale*

I clienti inviano alla piattaforma le richieste di polizza in formato EDI. Queste richieste devono essere acquisite, trasformate e salvate in un database backend, quindi convertite in documenti di polizza PDF per l'archiviazione. Il database risiede su un'infrastruttura separata e non è accessibile direttamente da OpenShift: è necessaria una soluzione di connettività sicura.

{empty} +

*La soluzione tecnica (da realizzare)*

Un'integrazione Apache Camel espone un endpoint API che riceve le richieste di polizza EDI in ingresso. Il flusso trasforma i dati EDI in formato XML, li salva in un database backend tramite {rhsi} e genera documenti di polizza PDF, che vengono caricati nell'object storage S3 (OpenShift Data Foundation).

{rhsi} consente una connettività sicura tra il cluster OpenShift e il database backend remoto senza esporre il database alla rete pubblica.

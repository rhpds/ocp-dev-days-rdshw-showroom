== Lab 4 - Assistenza clienti con AI

Usa un agente AI per orchestrare le azioni di backend in base alle conversazioni in linguaggio naturale: il tutto grazie ad Agentic Apache Camel e Model-as-a-Service (MaaS).

{empty} +

*L'esigenza aziendale*

Quando un cliente contatta l'assistenza per una pratica assicurativa, che si tratti di aggiornare i dettagli, modificare la copertura o risolvere una discrepanza, gli agenti di supporto devono tradizionalmente navigare manualmente tra più database e file system di backend per gestire la richiesta. È un processo lento, soggetto a errori e frustrante sia per gli agenti sia per i clienti. Serve un modo più rapido e senza attriti per gestire questi casi.

{empty} +

*La soluzione tecnica*

Gli agenti di supporto interagiscono con un bot AI direttamente nella finestra di Rocket.Chat, usando il linguaggio naturale. Grazie ad Agentic Apache Camel e Model-as-a-Service (MaaS), l'AI agisce da assistente intelligente: interpreta la richiesta dell'agente, decide autonomamente quali strumenti usare, aggiorna il database e rigenera il documento della polizza corretto nello storage S3. Questo riduce drasticamente i tempi di risoluzione ed elimina le attività manuali che costringono i team di supporto a passare continuamente da un sistema all'altro.

{empty} +

L'agente AI segue un ciclo di ragionamento: consulta l'LLM tramite MaaS, che decide quali azioni eseguire. Camel esegue quindi gli strumenti appropriati tramite *MCP* (aggiorna il database, rigenera un documento PDF della polizza in S3), restituisce i risultati all'LLM e invia la risposta finale all'agente di supporto in Rocket.Chat.

[NOTE]
====
*Che cos'è MCP?* Il Model Context Protocol (MCP) è uno standard aperto che consente agli agenti AI di interagire con sistemi esterni — database, API, file storage e altro — usando un insieme coerente di strumenti. In questo lab, Apache Camel implementa un server MCP che espone le azioni di backend (ad esempio, aggiornare il database e caricare file su S3) come strumenti invocabili. Il modello AI decide quali strumenti richiamare in base alla richiesta dell'utente in linguaggio naturale.
====

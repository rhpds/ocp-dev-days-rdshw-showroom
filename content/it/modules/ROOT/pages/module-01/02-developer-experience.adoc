=== Esercizio 3: aggiungi l'endpoint per le statistiche sui sinistri

Ora implementa la funzionalità. Creerai un nuovo endpoint REST che restituisce statistiche sui sinistri (totali e suddivisioni per categoria e stato).

. Torna a Dev Spaces e fai clic sull'icona **Explorer** nella barra laterale sinistra. Nella struttura dei file, espandi `src` -> `main` -> `java` -> `com` -> `parasol`.

. Fai clic con il pulsante destro del mouse sulla directory `parasol` e seleziona **New File**. Chiamalo `ClaimsStatsResource.java`.
+
Il percorso completo deve essere `src/main/java/com/parasol/ClaimsStatsResource.java`.
+
WARNING: Assicurati di creare il file nella cartella `parasol`, non in `com`, non in `java` e non nella directory principale del progetto. Se lo crei nella posizione sbagliata, in seguito si verificheranno errori di build e di Route nella pipeline.
+
image::parasol-app-newfile.png[Dashboard dell'applicazione Parasol Insurance,link=self,window=blank,width=700]

. Copia e incolla il codice seguente nel nuovo file:
+
[source,java,role="copypaste"]
----
package com.parasol;

import java.util.HashMap;
import java.util.Map;

import jakarta.inject.Inject;
import jakarta.ws.rs.GET;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.Produces;
import jakarta.ws.rs.core.MediaType;

@Path("/api/claims/stats")
@Produces(MediaType.APPLICATION_JSON)
public class ClaimsStatsResource {

    @Inject
    ClaimsResource claimsResource;

    @GET
    public Map<String, Object> getStats() {
        Map<String, Object> stats = new HashMap<>();

        System.out.println("Fetching claim statistics");

        try {
            var claims = claimsResource.getAllClaims();
            stats.put("total", claims.size());

            Map<String, Long> byCategory = new HashMap<>();
            for (var claim : claims) {
                byCategory.merge(claim.getCategory(), 1L, Long::sum);
            }
            stats.put("by_category", byCategory);

            Map<String, Long> byStatus = new HashMap<>();
            for (var claim : claims) {
                byStatus.merge(claim.getStatus(), 1L, Long::sum);
            }
            stats.put("by_status", byStatus);
        } catch (Exception e) {
        }

        return stats;
    }
}
----
+
NOTE: Questo codice funziona, ma contiene alcune scorciatoie. Hai usato `System.out.println` invece di un framework di logging appropriato e il blocco `catch` ignora silenziosamente le eccezioni. Questi code smell sono intenzionali: la pipeline CI/CD li rileverà nella Sezione 4.

. Salva il file con kbd:[Ctrl+S] (o kbd:[Cmd+S] su Mac). La modalità dev di Quarkus rileva la modifica e ricarica l'applicazione: non è necessario eseguire manualmente una build.
+
TIP: Se l'applicazione non si ricarica automaticamente, controlla il terminale in Dev Spaces per verificare che non ci siano errori di compilazione. Puoi anche riavviare la modalità dev premendo kbd:[Ctrl+Shift+P], selezionando **Tasks: Run Task** -> **devfile** -> **Start Development Mode (Hot Reload + debug)**. Se visualizzi un conflitto di porta, prima arresta il task esistente.

. Nel browser, passa alla scheda dell'applicazione Parasol in esecuzione, rimuovi `dashboard.html` dall'URL e aggiungi `/api/claims/stats` alla fine dell'URL nella barra degli indirizzi.
+
Dovresti vedere dati JSON con i totali e le suddivisioni dei sinistri:
+
----
{
  "total": 15,
  "by_category": {
    "auto": 5,
    "home": 4,
    "life": 6
  },
  "by_status": {
    "open": 8,
    "closed": 7
  }
}
----
+
Il nuovo endpoint funziona. Hai scritto il codice, salvato il file e l'applicazione si è ricaricata in pochi secondi. Nessun comando di build, nessun nuovo packaging, nessun nuovo deploy.
+

package com.parasol;

import java.util.HashMap;
import java.util.Map;

import io.quarkus.logging.Log;
import jakarta.ws.rs.GET;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.Produces;
import jakarta.ws.rs.core.MediaType;

@Path("/api/claims/stats")
@Produces(MediaType.APPLICATION_JSON)
public class ClaimsStatsResource {

    private final ClaimsResource claimsResource;

    public ClaimsStatsResource(ClaimsResource claimsResource) {
        this.claimsResource = claimsResource;
    }

    @GET
    public Map<String, Object> getStats() {
        Map<String, Object> stats = new HashMap<>();

        Log.info("Fetching claim statistics");

        try {
            var claims = claimsResource.getAllClaims();
            stats.put("total", claims.size());

            Map<String, Long> byCategory = new HashMap<>();
            for (var claim : claims) {
                byCategory.merge(claim.getCategory(), 1L, Long::sum);
            }
            stats.put("by_category", byCategory);

            Map<String, Long> byStatus = new HashMap<>();
            for (var claim : claims) {
                byStatus.merge(claim.getStatus(), 1L, Long::sum);
            }
            stats.put("by_status", byStatus);
        } catch (Exception e) {
            Log.error("Error fetching claim statistics", e);
        }

        return stats;
    }
}

== 所要時間

このモジュールのハンズオン作業には **60〜90 分** かかります。

[cols="2,1,3",options="header"]
|===
| セクション | 所要時間 | 内容

| 脆弱性への早期対応
| 15 分
| セキュリティ強化済みコンポーネントを確認し、サンドボックスを作成して、RHDA で依存関係の脆弱性を検出・修正する

| commit への署名
| 10 分
| Sigstore のキーレス署名で commit に署名し、GitLab で署名を検証する

| サンドボックスの pipeline を確認
| 15 分
| pipeline のセキュリティチェック、署名検証、ACS スキャン結果を確認し、ベースイメージを修正する

| 次のステージへ進む
| 25 分
| merge request を作成し、タグを使って昇格させ、署名済みの承認で Conforma のポリシー違反を解決する

| namespace を保護
| 10 分
| 署名のないイメージと未承認のイメージを deploy し、Policy Controller による適用をテストする
|===

== 技術スタック

このモジュールでは、モジュール 1 の技術に加え、セキュリティ関連の以下の技術も使用します。

* **Red Hat Trusted Artifact Signer (RHTAS)** -- Sigstore ベースの署名インフラストラクチャ（Fulcio、Rekor、TUF）
* **gitsign** -- OIDC を通じて開発者の ID と紐付ける、Sigstore のキーレス commit 署名
* **Tekton Chains** -- pipeline 成果物への自動署名と SLSA provenance attestation
* **Conforma (Enterprise Contract)** -- 署名済み attestation を Rego ポリシーに照らして検証するポリシーエンジン
* **Sigstore Policy Controller** -- deploy 時にイメージ署名と attestation を検証する Kubernetes admission controller
* **Red Hat Advanced Cluster Security (ACS)** -- イメージの脆弱性スキャンとセキュリティポリシーの適用
* **Red Hat Dependency Analytics (RHDA)** -- 依存関係の脆弱性をリアルタイムに分析する IDE 拡張機能
* **Trusted Profile Analyzer (TPA)** -- Lightwell の修正データを備え、SBOM を管理する脆弱性インテリジェンスバックエンド
* **Quay** -- 署名と attestation を保存できるコンテナイメージレジストリ
* **SonarQube** -- 静的解析とコード品質スキャン
* **Parasol Insurance (Secured)** -- サプライチェーンセキュリティを全面的に適用した、サンプル Quarkus アプリケーションの強化版

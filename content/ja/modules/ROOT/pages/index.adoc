= OpenShift Dev Day Roadshow
include::partial$_attributes.adoc[]

OpenShift Dev Day Roadshow へようこそ。ここでは、Red Hat OpenShift 上で最新のアプリケーション開発と統合を体験できる、ハンズオン形式のワークショップ集を提供します。

== 利用可能なモジュール

この Roadshow は独立したモジュールで構成されています。各モジュールは単独で完了することも、複数のモジュールを順に進めて OpenShift の機能を包括的に理解することもできます。

[.tile]
****
xref:module-01/00-intro.adoc[モジュール 1: 開発者体験]

Developer Hub によるセルフサービスのオンボーディングから、Dev Spaces を使ったクラウドベースの開発、AI 支援コーディング、自動化された CI/CD パイプライン、そして GitOps 主導の本番デプロイメントまで、OpenShift 上での開発者ジャーニー全体を体験します。

**所要時間**: 約 90 分
****

[.tile]
****
xref:module-02/00-intro.adoc[モジュール 2: セキュアなソフトウェアサプライチェーン]

RHDA と ACS による脆弱性スキャン、Sigstore によるコミットの鍵不要署名、Tekton Chains によるパイプライン証跡、Conforma によるポリシー検証、署名付きリリース承認、Policy Controller によるデプロイメント強制を通じて、SLSA Level 3 準拠のソフトウェアサプライチェーンでアプリケーションを構築およびデプロイします。

**所要時間**: 約 90 分
****

[.tile]
****
xref:module-03/index.adoc[モジュール 3: AI 向けアプリケーション接続]

Red Hat の統合技術を使用して AI データフローを構築します。Service Interconnect による EDI 取り込み、Kafka と Matrix / Rocket.Chat によるイベント駆動メッセージング、AI カスタマーサポート向けの Agentic Apache Camel、そして Connectivity Link による LLM ガバナンスを扱います。

**所要時間**: ラボによって異なります
****

[.tile]
****
xref:module-05/module-05-01-goals.adoc[モジュール 5: MTA を使用した AI 支援マイグレーション]

Migration Toolkit for Applications (MTA) に対して Red Hat Developer Lightspeed を活用し、レガシーな Java EE / EAP アプリケーションを Quarkus へモダナイズします。静的解析、AI 支援リファクタリング、カスタムルール、OpenShift へのデプロイメントを行います。

**所要時間**: 約 30 分
****

== はじめに

上のモジュールを選択して開始してください。各モジュールには、独自の導入、環境の詳細、学習目標が含まれています。

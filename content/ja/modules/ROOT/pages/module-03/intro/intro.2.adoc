== 開発環境

以下の手順では、このワークショップ全体でアプリケーションをデプロイする開発環境とクラスターについて説明します。

=== 概要

オープンソースの Eclipse Che プロジェクトを基盤とする Red Hat OpenShift Dev Spaces は、Kubernetes とコンテナーを使用して、開発チームや IT チームの誰もが一貫性があり、安全で、設定不要の開発環境を利用できるようにします。ノートパソコン上の統合開発環境と同じくらい高速で、使い慣れた操作感を提供します。

[.text-center]
image::module-03/intro/devspaces-ide-developer.png[width=70%]

OpenShift Dev Spaces は OpenShift サブスクリプションに含まれており、Operator Hub で利用できます。開発チームには、より高速で信頼性の高い作業基盤を提供し、運用チームには一元的な管理と安心感をもたらします。

{empty} +

=== コマンドのコピー/貼り付け

ラボ全体を通してコマンド操作を行います。 +
ラボの手順で実行するコマンドが示されたら、図のとおりに次の手順を実行してください:

image::module-03/intro/copypaste.png[width=60%]

{blank}

. *Copy to clipboard* ボタンをクリックします
. コマンドをターミナルに貼り付けます:
- Linux の場合: kbd:[Ctrl+Shift+v]
- Mac の場合: kbd:[⌘+v]
+
. 次のコマンドで試してみます:
+
[.copypaste]
****
echo "this is a multiline \
copy/paste test"
****
+
[NOTE]

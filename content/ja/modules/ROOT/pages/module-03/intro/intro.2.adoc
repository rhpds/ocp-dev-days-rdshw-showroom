== 開発環境

以下の手順では、このワークショップを通じてアプリケーションを deploy する開発環境と cluster を紹介します。

=== 概要

オープンソースの Eclipse Che を基盤とする Red Hat OpenShift Dev Spaces は、Kubernetes と container を使用して、開発チームや IT チームのメンバーに一貫性があり、安全で、設定不要の開発環境を提供します。ノート PC 上の統合開発環境と同じくらい、すばやく使い慣れた操作感で利用できます。

[.text-center]
image::module-03/intro/devspaces-ide-developer.png[width=70%]

OpenShift Dev Spaces は OpenShift サブスクリプションに含まれており、Operator Hub から利用できます。開発チームには、より迅速で信頼性の高い作業基盤を提供し、運用チームには一元管理による安心感をもたらします。

{empty} +

=== コマンドのコピーと貼り付け

ラボ全体を通じて、コマンドを実行します。 +
ラボの手順に実行するコマンドが記載されている場合は、以下に示す手順を実行します。

image::module-03/intro/copypaste.png[width=60%]

. _Copy to clipboard_ ボタンをクリックします。
. コマンドを Terminal に貼り付けます。
- Linux の場合: kbd:[Ctrl+Shift+v]
- Mac の場合: kbd:[⌘+v]
+
. 次のコマンドで試してみましょう。
+
[.copypaste]
****

copy/paste test"
****

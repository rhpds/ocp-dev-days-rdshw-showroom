== ラボの作業フォルダーをセットアップする

[.indent2]
include::../_shared/close-tabs.adoc[]

. ターミナルで _Dev Spaces_ から次の操作を行います:
.. 実行中のプロセスがある場合は、kbd:[Ctrl+C] で停止します。
.. 次のコマンドを実行します: +
(このコマンドを実行する前に、開いている Camel のファイルタブをすべて閉じてください — コマンド実行後に自動更新されない場合があります)
+
{blank}
+
[.copypaste]
****
step 4
****
+
[TIP]
--
上記のコマンドは、演習をいつでもリセットするために実行できます。

. ヘルプ用コマンド
[%collapsible]
====
* `step N` — ラボをステップ N の開始時点にリセットします
* `steps` — ラボで利用可能なすべてのステップを一覧表示します
* `start` または `restart` — いちばん最初に戻ります（`step 1` と同等です）
* `ff` — 次のステップへ早送りします
* `rw` — 前のステップへ巻き戻します
====
--
+
{empty} +

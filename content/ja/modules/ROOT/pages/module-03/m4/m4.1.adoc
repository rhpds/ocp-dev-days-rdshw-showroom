. Kafka と Matrix の統合を有効にする
+
======
Matrix との Kafka 統合をスケールアップします。

[.copypaste]
****
oc scale deployment k2m --replicas=1
****

この pod により、次の通知フローが有効になります。

[TIP]

上記のコマンドは、いつでも実行して演習をリセットできます。
[%collapsible]
====
ワークショップには、任意のステップへ移動したり、既知の正常な状態にラボをリセットしたりできる便利なヘルパースクリプトが含まれています。

* `step N` — ラボを step N の開始時点にリセットする
* `steps` — ラボで利用可能なすべてのステップを一覧表示する
* `start` または `restart` — 最初の状態に戻る（`step 1` と同等）
* `ff` — *次の* ステップへ早送りする
* `rw` — *前の* ステップへ巻き戻す
====

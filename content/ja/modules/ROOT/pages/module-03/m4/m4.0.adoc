== Lab 4 - AI Customer Support

自然言語チャットに基づいてバックエンドのアクションをオーケストレーションするために AI エージェントを使用します — Agentic Apache Camel と Model-as-a-Service (MaaS) を活用しています。

{empty} +

*ビジネス上の必要性*

お客様がポリシー申請について問い合わせてきたとき — 詳細の更新、補償範囲の変更、差異の解消など、内容はさまざまですが — 従来、サポート担当者は複数のバックエンドデータベースやファイルシステムを手作業で行き来して依頼に対応する必要がありました。これは遅く、ミスが起こりやすく、担当者にとってもお客様にとっても負担です。これらのケースを、もっと速く、摩擦なく処理できる方法が必要です。

{empty} +

*技術的な解決策*

サポート担当者は、Rocket.Chat のウィンドウ内で自然言語を使い、AI ボットと直接やり取りします。Agentic Apache Camel と Model-as-a-Service (MaaS) により、この AI は賢いアシスタントとして機能し、担当者の依頼を解釈し、呼び出すべきツールを自律的に判断し、データベースを更新し、S3 ストレージ内の修正済みポリシードキュメントを再生成します。これにより解決時間が大幅に短縮され、サポートチームの手作業による「スイベルチェア」業務がなくなります。

{empty} +

AI エージェントは推論ループに従います — MaaS を介して LLM に相談し、そこでどのアクションを取るかを決定します。次に Camel が *MCP* を通じて適切なツールを実行し（データベースの更新、S3 内の PDF ポリシードキュメントの再生成）、結果を LLM にフィードバックし、最終回答を Rocket.Chat のサポート担当者に返します。

[NOTE]
====
*MCP とは何ですか?* Model Context Protocol (MCP) は、AI エージェントがデータベース、API、ファイルストレージなどの外部システムと、一貫したツールセットを使って連携できるようにするオープン標準です。このラボでは、Apache Camel が MCP サーバーを実装し、バックエンドのアクション（例: データベースの更新、S3 へのアップロード）を呼び出し可能なツールとして公開します。AI モデルは、ユーザーの自然言語リクエストに基づいて、どのツールを呼び出すかを決定します。
====

{empty} +

*このラボで行うこと:*

. *環境をセットアップする* — 作業フォルダーを準備し、AI エージェントを設定します。
. *エージェントを開発する* — 基本ルートから、ツールを備えた完全な構成まで、AI エージェントを段階的に有効化します。
. *フローを完成させる* — Rocket.Chat、AI エージェント、データベース、S3 ストレージを結ぶ統合を仕上げます。
. *フローをテストする* — お客様/担当者のやり取りをシミュレーションし、結果を検証します。

{empty} +

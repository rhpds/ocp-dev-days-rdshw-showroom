=== 開発ループを開始する

ここからは、素早い開発サイクルで作業します。_Camel JBang_ は dev モードで動作するため、ルートに加えた変更はすぐに反映されます。フローを修正してファイルを保存すると、再起動せずに新しい動作をすぐ確認できます。

まずは、プレースホルダーの動作を確認するために、現在のまま Camel ルートを実行します。

{blank}

[.copypaste]
****
camel run agent --dev
****

[TIP]
--
.このコマンドは何をしますか？
[%collapsible]
====
* `camel run agent` — `agent` ディレクトリ配下のリソースを読み込み、その中で定義されたルートを実行します。
* `--dev` — dev モード。ソースファイルを保存すると自動的に再読み込みされます。
====
--

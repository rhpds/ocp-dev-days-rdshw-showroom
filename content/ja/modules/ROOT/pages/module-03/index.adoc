== AI のためのアプリケーション接続

ようこそ、 __AI 向けアプリケーション接続__ モジュールへ。このモジュールでは、Red Hat の強力なツールとテクノロジーを使って AI データフローを構築する方法を幅広く紹介します。AI が初めての方も経験豊富な開発者も、このワークショップを通じて、AI アプリケーションを支える効率的で安全なデータフローの作成方法を学べます。

[TIP]
--
最適な学習体験のため、モジュールは順番に進めることをおすすめします。各セクションは前の内容を踏まえているため、スキルと概念への理解を段階的に深められます。もちろん、特に興味のあるセクションだけを選んでもかまいません。
--

以下からモジュールを選択して開始してください。

[.tile]
****
xref:module-03/intro/intro.1.adoc[はじめに]

ワークショップの目的、使用するテクノロジー、シナリオを確認し、開発環境をセットアップします。
****

[.tile]
****
xref:module-03/m1/m1.0.adoc[ラボ 1 -- 取り込みサービス]

EDI ポリシー申請を取り込んで変換し、バックエンドデータベースに保存します。さらに、Service Interconnect による安全なクロスクラスター接続を利用して、PDF のポリシードキュメントを生成します。
****

[.tile]
****
xref:module-03/m2/m2.0.adoc[ラボ 2 -- メッセージングアクセス]

Matrix と Rocket.Chat のプラットフォームを利用開始し、2 つのメッセージングシステムを接続する最初の統合フローを確認します。
****

[.tile]
****
xref:module-03/m3/m3.0.adoc[ラボ 3 -- マルチチャネルハブ]

Kafka を基盤にメッセージングアーキテクチャを疎結合化し、標準データモデルを採用して、イベント駆動型ソリューション全体を OpenShift にデプロイします。
****

[.tile]
****
xref:module-03/m4/m4.0.adoc[ラボ 4 -- AI カスタマーサポート]

Agentic Apache Camel と MaaS でオーケストレーションされた AI サポートエージェントを構築し、Rocket.Chat で自然言語を使ってポリシーに関する問題を解決します。
****

[.tile]
****
xref:module-03/m5/m5.0.adoc[ラボ 5 -- LLM ガバナンス]

Red Hat Connectivity Link を使って LLM へのアクセスを保護し、ガバナンスを適用します。API キー認証と、ユーザー層ごとのトークンベースのレート制限を設定します。
****

== AI向けアプリケーション接続

__AI向けアプリケーション接続__へようこそ。このモジュールは、Red Hatの強力なツールとテクノロジーを使用してAIデータフローを構築するための包括的な入門を提供するように設計されています。AIの初心者でも経験豊富な開発者でも、このワークショップでは、AIアプリケーションを強化できる効率的で安全なデータフローを作成するプロセスをガイドします。

[TIP]
--
最良の体験のために、モジュールを順番に進めることをお勧めします。各セクションは前のセクションに基づいて構築されており、概念のスキルと理解を徐々に開発できますが、最も興味のある特定のセクションを自由に選択してください。
--

以下のモジュールを選択して開始してください。

[.tile]
****
xref:module-03/intro/intro.1.adoc[はじめに]

ワークショップの目標、使用するテクノロジー、シナリオを理解し、開発環境をセットアップします。
****

[.tile]
****
xref:module-03/m1/m1.0.adoc[ラボ 1 -- インジェストサービス]

EDI保険申請書をインジェストし、変換してバックエンドデータベースに保存し、PDF保険証券ドキュメントを生成 — Service Interconnectによる安全なクラスター間接続で実現。
****

[.tile]
****
xref:module-03/m2/m2.0.adoc[ラボ 2 -- メッセージングアクセス]

MatrixとRocket.Chatプラットフォームにオンボードし、両方のメッセージングシステムを接続する最初の統合フローを探索します。
****

[.tile]
****
xref:module-03/m3/m3.0.adoc[ラボ 3 -- マルチチャネルハブ]

Kafkaをバックボーンとして使用してメッセージングアーキテクチャを分離し、標準データモデルを採用し、OpenShift上に完全なイベント駆動ソリューションをデプロイします。
****

[.tile]
****
xref:module-03/m4/m4.0.adoc[ラボ 4 -- AIカスタマーサポート]

Rocket.Chatで自然言語を通じて保険問題を解決するAI駆動のサポートエージェントを構築 — Agentic Apache CamelとMaaSによってオーケストレーション。
****

[.tile]
****
xref:module-03/m5/m5.0.adoc[ラボ 5 -- LLMガバナンス]

Red Hat Connectivity LinkでLLMアクセスを保護し、管理 — ユーザー層ごとのAPIキー認証とトークンベースのレート制限を適用。
****

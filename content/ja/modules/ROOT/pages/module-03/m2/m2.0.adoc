== ラボ 2 - メッセージングアクセス

このワークショップで使用する 2 つのメッセージングプラットフォーム — Matrix と Rocket.Chat — に慣れ、両方にログインして、これからの統合演習に備えましょう。

{empty} +

=== メッセージングのシナリオ

Policy Applications を提出した顧客は、苦情、保険内容に関する質問、既存ポリシーの変更など、カスタマーサポートへ連絡する必要がある場合があります。その一方で、サポート担当者はいつでも対応できるよう準備しています。

興味深いのは、両者が *別々の* メッセージングプラットフォームを使っていることです。

* *Matrix* — 顧客が問い合わせを送る場所
* *Rocket.Chat* — サポート担当者が作業し、返信する場所

[TIP]
--
.これらのプラットフォームは何ですか?
[%collapsible]
====
Matrix と Rocket.Chat は、Slack、Telegram、WhatsApp に似たメッセージングプラットフォームです。このワークショップでは、OpenShift 上で自己ホストできるため、外部アカウントが不要なことからこれらを使用しています。

*Matrix* は、リアルタイムの分散型コミュニケーションのためのオープン標準および通信プロトコルです。異なるサービスプロバイダー間でもシームレスに動作します。

*Rocket.Chat* は、厳格なデータ保護基準を備えたオープンソースのコミュニケーションプラットフォームです。Web、デスクトップ、モバイルの各デバイスを通じて、同僚、他社、または顧客とのリアルタイム会話を可能にします。
====
--

今後のモジュールでは、Apache Camel と Kafka を使って両方のプラットフォームをつなぐ統合を構築します。その結果、一方から送られたメッセージが、もう一方にもシームレスに表示されるようになります。

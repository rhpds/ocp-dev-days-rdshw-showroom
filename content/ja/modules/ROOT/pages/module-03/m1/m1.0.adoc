== はじめに



顧客からデータを取り込み、バックエンドデータベースに保存し、PDF のポリシー文書を生成します。これらすべてを Apache Camel でオーケストレーションし、{rhsi} による安全なクラスター間接続を実現します。

{empty} +

*ビジネスニーズ*

顧客は EDI 形式の保険契約申請書をプラットフォームに送信します。これらの申請書は取り込まれ、変換され、バックエンドデータベースに保存された後、アーカイブ用の PDF ポリシー文書としてレンダリングされる必要があります。データベースは別のインフラストラクチャ上にあり、OpenShift から直接アクセスできないため、安全な接続ソリューションが必要です。

{empty} +

*構築する技術ソリューション*

Apache Camel インテグレーションが API エンドポイントを公開し、受信した EDI 形式の保険契約申請書を受け取ります。フローでは EDI データを XML 形式に変換し、{rhsi} を介してバックエンドデータベースに保存するとともに、PDF のポリシー文書をレンダリングして S3 オブジェクトストレージ（OpenShift Data Foundation）にアップロードします。

{rhsi} により、データベースをパブリックネットワークに公開せずに、OpenShift クラスターとリモートのバックエンドデータベースとの間で安全な接続を確立できます。

{empty} +

*このラボで行うこと:*

. *接続を有効にする* — {rhsi} を設定して、バックエンドデータベースへの安全なリンクを確立します。
. *フローを完成させる* — 保険契約申請書を取り込み、変換、保存、レンダリングする Camel インテグレーションを実装します。
. *テストして検証する* — フローをローカルで実行し、結果を検証します。

== はじめに



顧客からデータを取り込み、バックエンドデータベースに保存し、PDF ポリシードキュメントを生成します。これらはすべて、{rhsi} による安全なクラスター間接続で Apache Camel がオーケストレーションします。

{empty} +

*ビジネスニーズ*

顧客は、ポリシー申請を EDI 形式でプラットフォームに送信します。これらの申請は取り込み、変換、バックエンドデータベースへの保存を行い、アーカイブ用の PDF ポリシードキュメントとして出力する必要があります。データベースは別のインフラストラクチャ上にあり、OpenShift から直接アクセスすることはできません。そのため、安全な接続ソリューションが必要です。

{empty} +

*技術ソリューション（構築するもの）*

Apache Camel の統合により API エンドポイントが公開され、受信した EDI ポリシー申請を受け取ります。このフローは EDI データを XML 形式に変換し、{rhsi} を介してバックエンドの Database に保存し、PDF ポリシードキュメントを生成して S3 オブジェクトストレージ（OpenShift Data Foundation）にアップロードします。

{rhsi} により、OpenShift クラスターとリモートのバックエンドデータベース間で、データベースをパブリックネットワークに公開することなく、安全な接続が実現します。

{empty} +

*このラボで行うこと:*

. *接続を有効化する* — {rhsi} を設定して、バックエンドデータベースへの安全なリンクを確立します。
. *フローを完成させる* — ポリシー申請の取り込み、変換、保存、レンダリングを行う Camel 統合を実装します。
. *テストして検証する* — フローをローカルで実行し、結果を検証します。

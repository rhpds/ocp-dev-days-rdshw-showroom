== はじめに



顧客データを取り込み、バックエンドデータベースに保存して、PDF の保険証券を生成します。これらすべてを Apache Camel でオーケストレーションし、{rhsi} を利用してクラスター間の安全な接続を実現します。

{empty} +

*ビジネスニーズ*

顧客は EDI 形式の保険契約申込書をプラットフォームに送信します。申込書を取り込んで変換し、バックエンドデータベースに保存したうえで、アーカイブ用の PDF 保険証券として生成する必要があります。データベースは別のインフラストラクチャ上にあり、OpenShift から直接アクセスできないため、安全な接続ソリューションが必要です。

{empty} +

*構築する技術ソリューション*

Apache Camel インテグレーションで API エンドポイントを公開し、EDI 形式の保険契約申込書を受信します。フローでは EDI データを XML 形式に変換して {rhsi} 経由でバックエンドデータベースに保存し、PDF 保険証券を生成して S3 オブジェクトストレージ（OpenShift Data Foundation）にアップロードします。

{rhsi} により、データベースをパブリックネットワークに公開することなく、OpenShift クラスターとリモートのバックエンドデータベース間に安全な接続を確立できます。

{empty} +

*このラボで行うこと:*

. *接続を有効にする* — {rhsi} を設定して、バックエンドデータベースへの安全なリンクを確立します。
. *フローを完成させる* — 保険契約申込書を取り込み、変換、保存し、証券を生成する Camel インテグレーションを実装します。
. *テストして検証する* — フローをローカルで実行し、結果を検証します。

このワークショップで編集する処理フローのほとんどは、Apache Camel 向けのビジュアルインテグレーションデザイナーである *Kaoto* を使用します。Kaoto は VS Code 拡張機能で、Camel の定義をグラフィカルに描画するため、YAML を手で編集せずにルートを設計・設定できます。

image::module-03/common/vs-code-kaoto.png[width=40%]

Kaoto を使うと、主に次のようなことができます。

* Camel ルートを作成する(処理フローを定義する主な方法)
* Kamelet を作成する(ルートで再利用できる部品)
* データ変換を作成する
* EIP(Enterprise Integration Patterns)を適用する

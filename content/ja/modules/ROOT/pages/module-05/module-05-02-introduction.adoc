Migration Toolkit for Applications は、長年にわたり、クラウド移行に向けてアプリケーションを評価および分析する業界をリードするソリューションとして利用されてきました。 **Developer Lightspeed** (**DLS**) は、MTA の **AI を活用したコードのリファクタリング** 機能であり、独立した拡張機能ではありません。生成 AI を活用した移行を開発者の IDE に取り入れ、アプリケーションのモダナイゼーションに対する組織の取り組み方を変革します。



== アプリケーションのモダナイゼーションにおける課題

企業がアプリケーションポートフォリオをモダナイズする際には、いくつかの重大な課題に直面します。

* **セキュリティ上の懸念** - 古いアプリケーションやフレームワークは、事業運営に重大なリスクをもたらし、データ侵害やコンプライアンス違反につながる可能性があります。
* **レガシーシステムの複雑さ** - レガシーコードベースは、最新のプラットフォームとの互換性がない、依存関係が密結合している、現在の開発チームにはなじみがない、といった問題を抱えていることがよくあります。
* **優先事項の競合** - 組織は、モダナイゼーションの緊急性と限られたリソースのバランスを取らなければならず、多くの場合、既存アプリケーションの改善よりも新機能を優先します。
* **規模と一貫性** - 大企業では、同様の変更が必要なアプリケーションが何百もある場合があり、手作業での移行は現実的ではありません。

Developer Lightspeed は、シンプルな 6 ステップの手法により、静的解析と生成 AI を活用したアプリケーション移行を容易にします。

== Developer Lightspeed がモダナイゼーションを変革する方法

**Red Hat Developer Lightspeed for MTA** は、静的解析と **Developer Lightspeed** (生成 AI) の両方を活用する MTA のモダナイゼーションを指します。IDE では、Visual Studio Code 用の **MTA extension** が、MTA の静的解析と Developer Lightspeed を一体的に提供します。この組み合わせにより、次の課題に対応できます。

* **GenAI でアプリケーションのモダナイゼーションを加速する** - MTA extension は、実績ある MTA の静的コード解析と Developer Lightspeed の生成 AI を組み合わせ、移行の問題を特定して、状況に応じた解決策を提案します。AI は IDE 内で直接、個々の状況に合わせたコードの提案を生成するため、コンテキストを切り替える必要がなく、開発者は作業に集中できます。システムはコード変更による影響を自動的に処理し、リファクタリングの全過程でコードの整合性を維持します。さらに、移行メトリクスを追跡し、過去の解決策から学習して、時間の経過とともに提案を継続的に改善します。

* **開発者が信頼できる、役立つリファクタリング済みコードの提案を得る** - このシステムはルールベースの解析を使用して、どの移行上の問題を探し、どのように解決するかを LLM に示すことで、提案が実績ある移行パターンに基づくようにします。各提案には、何を変更する必要があるのか、なぜ変更が必要なのかが明確に説明されており、開発者は修正案の根拠を理解できます。IDE のリアルタイム診断データにより、修正は仮定上の問題ではなく、実際のコンパイル時および実行時の問題に対応します。開発者は全過程を通じて変更をレビューし、承認するため、リファクタリングを完全に管理し、コード品質を確保できます。

* **カスタム技術や独自技術をモダナイズする** - Developer Lightspeed では、組織固有のフレームワークに対する条件とアクションを定義するカスタムルールを作成できるため、AI が独自のテクノロジースタックを理解し、扱えるようになります。この機能により、標準の移行ルールでは対象にならない独自または社内のライブラリーを使用するアプリケーションのコード変換を自動化できます。組織の知識を活用して標準提供の移行パスを拡張し、特定のビジネスニーズに合わせてツールを適応させます。

* **ポートフォリオ全体でモダナイゼーションを拡大する** - Developer Lightspeed は、移行中に行われた変更から学習し、時間とともに向上する組織の知識を蓄積します。複数のアプリケーションで類似パターンに遭遇すると、ポートフォリオ内の類似アプリケーションに対する解決策を正確に予測して生成します。この学習機能により、一貫した品質を保ちながら複数のアプリケーションを効率よく予測可能な形でリファクタリングでき、ポートフォリオ規模のモダナイゼーションが実現します。

* **開発ワークフローにシームレスに統合する** - すべての解析とリファクタリングは Red Hat Dev Spaces 内で直接行われるため、開発者は使い慣れた環境で作業できます。詳細な問題、提案された解決策、コード差分を、コンテキストを切り替えたり別のツールに移動したりせずに確認できます。リファクタリングが完了したら、既存の CI/CD パイプラインを通じてリファクタリング済みコードをプッシュし、自動テストとデプロイを実行できます。これにより、モダナイズされたアプリケーションを確立済みの開発プロセスにシームレスに統合できます。

* **AI モデルを選択する** - Developer Lightspeed は、ファインチューニングなしで、パブリックまたはセルフホストのカスタム LLM を使用できるため、ベンダーロックインを回避できます。RAG アーキテクチャは過去の解決策から学習してナレッジベースに保存し、組織の移行履歴に基づいて提案を継続的に改善します。このシステムは OpenAI 互換 API を通じて複数の LLM プロバイダーに対応しており、Red Hat OpenShift AI (エンタープライズ向けモデルビルダーおよび推論サーバー)、Red Hat Enterprise Linux AI (エンタープライズ向け推論サーバー)、vLLM (広く利用されているエンタープライズ向け推論サーバー) が含まれます。この柔軟性により、特定の要件に応じてパフォーマンス、コスト、データプライバシーのバランスを取ることができます。

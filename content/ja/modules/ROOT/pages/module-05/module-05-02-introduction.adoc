Migration Toolkit for Applications は、長年にわたり、クラウド移行に向けてアプリケーションを評価し分析するための業界をリードするソリューションでした。**Developer Lightspeed** (**DLS**) は、MTA の **AI-powered code refactoring** 機能であり、別個の拡張機能ではありません。生成 AI 支援による移行を開発者の IDE に取り込み、組織がアプリケーションのモダナイゼーションに取り組む方法を変革します。



== アプリケーションモダナイゼーションの課題

企業がアプリケーションポートフォリオをモダナイズする際には、いくつかの重要な課題に直面します。

* **セキュリティ上の懸念** - 古いアプリケーションやフレームワークは、ビジネス運用に重大なリスクをもたらし、データ侵害やコンプライアンス違反につながる可能性があります。
* **レガシーシステムの複雑さ** - レガシーなコードベースは、最新のプラットフォームとの互換性が不足していたり、密結合の依存関係を抱えていたり、現在の開発チームにはなじみがなかったりすることがよくあります。
* **競合する優先事項** - 組織は、モダナイゼーションの緊急性と限られたリソースのバランスを取る必要があり、多くの場合、既存アプリケーションの改善よりも新機能を優先します。
* **規模と一貫性** - 大企業では、同様の変更を必要とするアプリケーションが何百も存在する場合があり、手作業での移行は現実的ではありません。

Developer Lightspeed は、シンプルな 6 ステップの方法論を用いて、静的解析と生成 AI を活用したアプリケーション移行を容易にします。

== Developer Lightspeed がモダナイゼーションをどう変革するか

**Red Hat Developer Lightspeed for MTA** は、静的解析と **Developer Lightspeed** (生成 AI) の両方を使用する MTA モダナイゼーションを指します。IDE では、Visual Studio Code 用の **MTA extension** が MTA の静的解析と Developer Lightspeed を一緒に提供します。この組み合わせは、次の課題に対応します。

* **GenAI でアプリケーションのモダナイゼーションを加速する** - MTA extension は、実績のある MTA の静的コード解析と Developer Lightspeed の生成 AI を組み合わせ、移行上の問題を特定し、コンテキストに応じた解決策を提案します。AI は、IDE 内で直接、個々の状況に合わせたコード推奨を生成するため、コンテキストの切り替えが不要になり、開発者は作業に集中できます。システムはコード変更による波及効果を自動的に処理し、リファクタリングのプロセス全体を通じてコードの整合性を維持します。さらに、移行メトリクスを追跡し、過去の解決策から学習することで、時間の経過とともに推奨内容を継続的に改善します。

* **開発者が信頼できる、役立つリファクタリング済みコードの提案を得る** - このシステムはルールベースの解析を使用して、LLM に対し、どの移行上の問題を探し、どのように解決すべきかをガイドし、推奨内容が実績のある移行パターンに基づくようにします。すべての提案には、何を変更する必要があるのか、そしてなぜそれが必要なのかについての明確な説明が含まれており、開発者が各提案修正の根拠を理解できるようにします。IDE のリアルタイム診断データにより、修正は仮説上の問題ではなく、実際のコンパイル時および実行時の問題に対応できます。プロセス全体を通じて、開発者が変更をレビューして承認するため、リファクタリングプロセスを完全に制御し、コード品質を確保できます。

* **カスタムおよび独自技術をモダナイズする** - Developer Lightspeed では、組織固有のフレームワークに対する条件とアクションを指定するカスタムルールを作成できるため、AI は独自のテクノロジースタックを理解し、それに対応できます。この機能により、標準の移行ルールでは扱われない独自ライブラリや社内ライブラリを使うアプリケーションのコード変換を自動化できます。組織の知識で標準提供の移行パスを拡張し、特定のビジネス要件に合わせてツールを適応させます。

* **ポートフォリオ全体でモダナイゼーションを拡張する** - Developer Lightspeed は、移行プロセスで行われた変更から学習し、時間の経過とともに改善される組織的な知識を蓄積します。アプリケーション間で類似パターンに遭遇すると、ポートフォリオ全体の類似アプリケーションに対する解決策を正確に予測し、生成します。この学習機能により、一貫した品質で、複数のアプリケーションを予測可能かつ効率的にリファクタリングでき、ポートフォリオ規模のモダナイゼーションを実現できます。

* **開発ワークフローへシームレスに統合する** - すべての解析とリファクタリングは Red Hat Dev Spaces 内で直接行われるため、開発者は使い慣れた環境のまま作業できます。詳細な問題点、提案された解決策、コード差分は、コンテキストを切り替えたり別のツールに移動したりすることなく確認できます。リファクタリングが完了したら、既存の CI/CD パイプラインを通じてリファクタリング済みコードをプッシュし、自動テストとデプロイを行うことで、モダナイズされたアプリケーションを確立済みの開発プロセスにシームレスに統合できます。

* **AI モデルを選択する** - Developer Lightspeed は、ファインチューニング不要で、カスタム LLM — パブリックでもセルフホストでも可 — の使用をサポートしており、ベンダーロックインを回避できます。RAG アーキテクチャは過去の解決策から学習してナレッジベースに保存し、組織の移行履歴に基づいて推奨内容を継続的に改善します。このシステムは、OpenAI 互換 API を通じて複数の LLM プロバイダーと互換性があり、Red Hat OpenShift AI (enterprise model builder & inference server)、Red Hat Enterprise Linux AI (enterprise inference server)、および vLLM (popular enterprise inference server) を含みます。この柔軟性により、特定の要件に応じてパフォーマンス、コスト、データプライバシーのバランスを取ることができます。

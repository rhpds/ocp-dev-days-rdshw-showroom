== Timing

This module is designed for **60-90 minutes** of hands-on work.

[cols="2,1,3",options="header"]

| Section | Duration | What you will do

| 15 min

| Signing your commits
| 10 min
| Sign a commit with Sigstore keyless signing and verify the signature in GitLab

| Checking the sandbox pipeline
| 15 min
| Review pipeline security checks, signature verification, ACS scan results, and fix the base image

| Moving to the next stages
| 25 min

| 10 min

|===

== Technology Stack

This module uses all the technologies from Module 1, plus the following security-focused additions:

* **Red Hat Trusted Artifact Signer (RHTAS)** -- Sigstore-based signing infrastructure (Fulcio, Rekor, TUF)
* **gitsign** -- Sigstore keyless commit signing, tied to developer identity via OIDC
* **Tekton Chains** -- Automatic pipeline artifact signing and SLSA provenance attestation
* **Conforma (Enterprise Contract)** -- Policy engine that validates signed attestations against Rego policies
* **Sigstore Policy Controller** -- Kubernetes admission controller that verifies image signatures and attestations at deployment time
* **Red Hat Advanced Cluster Security (ACS)** -- Image vulnerability scanning and security policy enforcement
* **Red Hat Dependency Analytics (RHDA)** -- IDE extension for real-time dependency vulnerability analysis
* **Trusted Profile Analyzer (TPA)** -- Vulnerability intelligence backend with Lightwell remediation data and SBOM management
* **Quay** -- Container image registry with signature and attestation storage
* **SonarQube** -- Static analysis and code quality scanning
* **Parasol Insurance (Secured)** -- Hardened variant of the sample Quarkus application with full supply chain security

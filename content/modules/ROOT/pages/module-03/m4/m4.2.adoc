.Why did the bot respond that way?
[caption=]
====
The AI agent doesn't have access to the tools it needs — the MCP servers haven't been wired in yet.

The `system.message` file contains the system prompt that guides the AI agent's behaviour. One of its rules explicitly instructs the model to decline when it lacks the right tool:

----
# CRITICAL CONSTRAINTS
* **NO TOOL, NO URL:** If there is no tool fit for the job (missing),
  you MUST return Pattern 2 with the text: "I'm sorry, I don't have 
  the capability to retrieve that PDF right now."
----

Once you register the tools, the agent will discover and use them automatically.
====

=== Wire in the MCP servers

The project includes MCP servers to provide the necessary tools for the Camel agentic flow — but the agent doesn't know about them yet. You need to wire them in to the agentic flow.

The diagram below shows how the Agentic Integration (once MCP is active) routes tool calls from the AI model. Two MCP servers provide distinct toolsets — Node.js and Camel Quarkus. When the AI model needs a tool, the Agentic Integration routes the request to the appropriate MCP server, which executes the tool against the backend systems and returns the result.

[TIP]
--
In Camel you don't need MCP servers to define tools. You can define them directly as regular routes that starts with the `langchain4j-tools` component. The route describes what the tool does — the agent discovers it automatically via tags and invokes it when needed.

For example, this is how you would define a local tool that retrieves the PDF URL for a given invoice:

image::module-03/m4/kaoto-tool-route.png[width=50%]

The route starts with the `langchain4j-tools` source, processes the request through a series of steps, and returns the result to the LLM. No special wiring is needed. Camel uses tags to match agents with tools — when an agent's tag matches a tool's tag, the agent can call that tool.
--

=== Raise a ticket

A customer support process rarely ends with a single action. Returning an item involves multiple departments — confirming the goods were received, processing the refund, updating inventory, notifying the customer. Rather than handling each step manually, ask the AI agent to raise a ticket that coordinates everything:

{blank}

[.copypaste]
****
Could you please raise a ticket? Include the details explained, and ask the right departments to refund the customer accordingly.
****

The agentic system gathers the context from the conversation, creates a ticket in the HelpDesk system, and responds with a confirmation:

{blank}
